## 加权投票规则

1. 计算每个商品的加权分：
   - 如果评审员判定 has_problem=false → 贡献 = 0
   - 如果评审员判定 has_problem=true → 贡献 = 置信度 × 权重
   - 加权分 = GPT-5.1贡献 + GPT-5.4贡献 + Gemini-2.5贡献

2. 确定问题类型（取多数评审员判定的类型）

3. 根据问题类型使用对应阈值（v4.1 更新）：
   - child_sexualization (儿童性化): 0.30（最高优先级，零容忍）
   - uncomfortable (怪异/不适): 0.40
   - vulgar (低俗/色情): 0.45
   - ansa (成人内容): 0.45
   - low_quality (图片低质): 0.35
   - 其他类型: 0.50

4. 判定：
   - 加权分 ≥ 类型阈值 → 最终判定有问题
   - 加权分 < 类型阈值 → 最终判定正常

5. 如果三位评审员的 reason 描述的是不同问题 → 倾向于判为正常

6. **空值处理**：如果评审员输出中 `reason` 为 `"SKIP_EMPTY_PRODUCT"`，说明该商品为空，直接跳过，最终裁决为正常，加权分=0

7. **v4.1 新增 PBR 规则检查**：
   - 如果判定为 vulgar/ansa/child_sexualization，检查评审员是否引用了正确的 PBR 规则编号
   - 规则引用格式："违反 PBR Rule X.Y.Z"
   - 规则引用不一致 → 加权分 × 0.8
